# sisyphe — Personal Homepage

A static personal homepage with an introduction, academic interests, coursework, perspectives, questions and reflections, and official learning resources.

## Preview and edit

Open `index.html` in a browser. Edit public contact information in `profile.js`, text in `index.html`, and appearance in `style.css`. No installation or build step is needed.

## Publish on GitHub Pages

Upload the files directly to the root of the public repository `sisyphe123.github.io`. In Settings > Pages, choose Deploy from a branch, then main and /(root). The expected website address after successful deployment is https://sisyphe123.github.io/ . Check the published page in a signed-out browser before submitting the URL.

This package contains the English website only, with no language switch or Chinese page.

## Typography

Body: Segoe UI, Helvetica Neue, Arial, sans-serif. Headings: Oswald, included as a local font under the SIL Open Font License (see OFL.txt). Upload Oswald-Variable.ttf and OFL.txt together with the other files. The layout follows the font pairing used by https://hsd1503.github.io/ .
